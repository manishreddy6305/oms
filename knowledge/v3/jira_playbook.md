# Working with Jira
Follow below steps when resolving/working an Jira ticket.

1. Fetch the user attributes, summary, title, description from jira ticket
2. Analyze the issue request available knowledge files for debugging help. 
3. Keep jira status updated at every stage of debugging. 
4. Request for available jira transitions and update the status accordingly. 
5. Close the ticket if you think the ticket is analyzed completely to an conclusion and no further action required from anyone. 
6. Assing the tickets to the respective persons which is next actionable to resume the debugging.
